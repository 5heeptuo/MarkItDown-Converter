# Product Description (≤350 chars)

**MarkItDown Converter** is an open-source Windows app that turns PDF, Word, Excel, PowerPoint, HTML, images, and scans into Markdown via drag-and-drop. Built on Microsoft MarkItDown with fully offline OCR and post-processing that restores reading order, spacing, and paragraphs. Batch conversion, Chinese/English/Spanish, 100% local, no uploads. MIT.
